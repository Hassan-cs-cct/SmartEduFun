Smart EduFun 📚🎮

Smart EduFun is a Final Year Project (FYP) developed by students of the Department of Computer Science, MNS University of Engineering & Technology, Multan.

The application is designed to make learning enjoyable and interactive for children by combining educational content with multimedia elements such as images, audio pronunciations, animations, and quizzes. Built using Flutter and Dart following the Model-View-Controller (MVC) architecture, Smart EduFun provides a child-friendly environment that encourages curiosity, creativity, and self-paced learning.
